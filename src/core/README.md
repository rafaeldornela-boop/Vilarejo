# Núcleo Central

Este diretório reúne a infraestrutura de runtime do projeto.

## Conteúdo esperado

- calendário e estado de simulação
- sessão e ciclo de vida
- barramento de eventos
- módulo registro e snapshots
- comunicação entre módulos

## Observação

A implementação atual continua compatível com os arquivos raiz enquanto a estrutura modular é migrada.
