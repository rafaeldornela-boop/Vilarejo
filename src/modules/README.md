# Módulos futuros

Este diretório está reservado para a evolução do sistema em módulos desacoplados.

## Módulos previstos

- Sociedade
- Política
- Legislação
- Infraestrutura
- Gestão institucional

## Regras

Módulos devem se integrar por eventos e contratos definidos, e não por manipulação direta do estado bruto.
