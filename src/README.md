# Estrutura de código do Vilarejo

Este diretório organiza a base do projeto em camadas de responsabilidade.

## Estrutura sugerida

- `src/core/` — runtime e coordenador
- `src/economy/` — motor econômico e finanças
- `src/modules/` — módulos futuros
- `src/shared/` — utilitários, contratos e helpers
- `src/tests/` — testes e validação
- `src/ui/` — interface visual
- `src/assets/` — mídia e recursos visuais

## Observação

A estrutura foi criada para preparar a arquitetura modular sem quebrar o comportamento funcional já validado do projeto.
