# Instalação do Vilarejo

O guia oficial e atualizado está em [`docs/gameplay/GUIA_INSTALACAO.md`](docs/gameplay/GUIA_INSTALACAO.md). Para executar o jogo, use `npm install`, `npm run build`, `npm test` e `npm start` na raiz deste repositório.

Este arquivo substitui as instruções anteriores de instalação por pacote/patch. `scripts/install.js`, `src/economy/script.js` e os patches referidos em documentos antigos não são o fluxo de instalação desta branch. Consulte [`docs/history/README.md`](docs/history/README.md) para identificar registros arquivados.
