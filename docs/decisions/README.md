# Decisões arquiteturais

As decisões são registros curtos de contexto, escolha, consequência e alternativas rejeitadas.

- [ADR-001 — Integrar sobre `main` sem reescrever a Economia](ADR-001-integracao-sobre-main.md): organização dos módulos, evento mensal, limites fiscais e preservação da branch base.

Antes de alterar contratos ou dependências, acrescente uma ADR com a motivação e os testes que sustentam a decisão.
