# Patches históricos

Estes patches foram conservados como registro da proposta de integração original. Eles não são parte da aplicação e não são usados por npm, HTML, build ou testes. Os contextos podem não existir mais e sua aplicação não é recomendada na branch atual.

A integração vigente está nos arquivos do repositório, documentada em [`docs/architecture/ARQUITETURA_GERAL_V1.md`](../../architecture/ARQUITETURA_GERAL_V1.md). Para validar alterações, use `npm run build` e `npm test`; não aplique os patches históricos em sequência.
